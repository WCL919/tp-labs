## Цель работы

Освоить базовый цикл работы с Git: инициализация локального репозитория,
создание первого коммита, привязка удалённого репозитория на GitHub и
отправка локальных коммитов на сервер.

## Используемое программное обеспечение

| Компонент | Версия |
| --- | --- |
| ОС | Windows 11 |
| Git | 2.55.0 |
| Хостинг | GitHub |

## Ход работы

### 1. Создание локального репозитория

```bash
git init
```

![Инициализация репозитория](img/01-init.png)

```bash
git status
```

![Статус файлов до добавления в индекс](img/02-status-untracked.png)

Все файлы проекта находятся в состоянии *untracked* — Git о них знает,
но в будущий коммит они пока не попадут.

### 2. Первый коммит

Добавляем файлы в индекс:

```bash
git add .
```

![Файлы добавлены в индекс](img/03-status-staged.png)

Указываем автора изменений:

```bash
git config --global user.name "Wei Chenlin"
git config --global --list
```

![Настройка имени и почты автора](img/04-git-config.png)

Создаём коммит:

```bash
git commit -m "Lab 1: initial repository setup"
```

![Создание первого коммита](img/05-commit.png)

Проверяем историю:

```bash
git log
```

![История коммитов](img/06-git-log.png)

### 3. Создание удалённого репозитория и привязка

Репозиторий создан на GitHub без инициализации (без README и .gitignore),
чтобы не возникло конфликта при первом пуше.

![Создание репозитория на GitHub](img/07-github-create-repo.png)

Настраиваем доступ по SSH и проверяем подключение:

```bash
ssh -T git@github.com
```

![Проверка SSH-подключения к GitHub](img/08-ssh-check.png)

Добавляем удалённый репозиторий:

```bash
git remote add origin git@github.com:WCL919/tp-labs.git
git remote -v
```

![Добавление удалённого репозитория](img/09-remote-add.png)

### 4. Отправка коммитов на сервер

```bash
git push -u origin master
```

![Пуш в удалённый репозиторий](img/10-push.png)

Ключ `-u` связывает локальную ветку с удалённой, поэтому дальше достаточно
команды `git push`.

### 5. Размещение отчёта в репозитории

Отчёт и скриншоты находятся в том же репозитории, поэтому отчёт
открывается прямо на GitHub.

![Отчёт в репозитории на GitHub](img/11-report-on-github.png)

## Вывод

В ходе работы был создан локальный Git-репозиторий, выполнены настройки
автора, создан первый коммит и настроена связь с удалённым репозиторием
на GitHub. Изменения успешно отправлены на сервер. Освоены базовые
команды `git init`, `git status`, `git add`, `git commit`, `git log`,
`git remote` и `git push`.
